## 📦 Website Features

### 1. **Responsive Design**
- Mobile-first approach
- Breakpoints: 320px (mobile), 480px (small mobile), 768px (tablet), 1024px (desktop), 1920px (large desktop)
- Hamburger menu for mobile navigation
- Touch-friendly interface

### 2. **Interactive Components**
- Animated hero slider with fade transitions
- Product filter with smooth animations
- Hover effects on cards and buttons
- Scroll-to-top button
- Smooth scrolling for internal links
- Parallax backgrounds
- AOS (Animate On Scroll) animations

### 3. **Bilingual Content**
- 70% Indonesian + 30% English throughout
- Professional translations
- Consistent language mixing across all pages
- Form labels in both languages

### 4. **Performance Optimizations**
- CSS optimization with custom properties (CSS variables)
- Debounced scroll events
- IntersectionObserver for lazy loading
- Efficient DOM queries
- Minified asset references

### 5. **SEO & Accessibility**
- Semantic HTML5 structure
- Meta tags on all pages
- Proper heading hierarchy
- Alt text for all images
- ARIA labels where appropriate
- Keyboard navigation support

### 6. **Forms & Validation**
- Client-side form validation (HTML5 + JavaScript)
- Email validation
- Phone number validation
- File upload validation (PDF, DOC, DOCX up to 5MB)
- Error/success message display
- Required field indicators
